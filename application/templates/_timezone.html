{# Tell the server which clock the user reads the page by. Timestamps are stored in UTC; the GUI shows them local, and `created:` in the host search means the user's day. The browser is the only place that knows the timezone, so it writes the IANA name plus the current UTC offset into a cookie that `application.helpers.timezone` reads back. Nothing breaks without it — the page then renders in UTC, as it always did. #}

Rules in Git

Move rules from one Syncer to another, e.g. from test to production: the test instance pushes the selected rule types into a Git repository, production pulls them from there. Every rule type is one JSON file in the repository, so its history shows what changed. Hosts, accounts, users and the Secret Store are not transferred, they belong to each instance. Documentation

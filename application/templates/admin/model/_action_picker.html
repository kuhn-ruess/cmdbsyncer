{# Card-based action picker for Checkmk rule outcomes. Replaces the long, hard-to-scan native stays in the DOM as the form's source of truth — clicking a card just sets its value — so nothing about submission, validation or select2 needs to change. Deprecated actions render greyed-out and unclickable (unless a legacy rule already uses one, so it stays visible for migration); server-side validation still blocks saving them. Card descriptions come from ACTION_CATALOG, so this template needs no per-action strings. #}

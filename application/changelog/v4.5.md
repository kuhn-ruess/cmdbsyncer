# Version 4.5

## Unreleased

- INCOMPATIBLE: SEC: A new password, set by the user, by a reset mail or by an admin, ends all other sessions of that user and revokes their personal API tokens. Everyone with a local password logs in once after the update; automation with such a token gets a 401 until its owner creates a new one under Profile, API Tokens
- INCOMPATIBLE: SEC: Password reset no longer logs in, so 2FA can't be bypassed with the mail alone; a disabled user gets no reset mail and loses a running session. The new setting `PUBLIC_URL` fixes the address in the link
- INCOMPATIBLE: SEC: Ansible is updated from 10.5 to 14.6 to close two vulnerabilities: the Ansible server needs Python 3.12, the targets Python 3.9 or newer. In own playbooks a `when` must give true or false, a plain string or number stops the task; the bundled playbooks are adapted
- INCOMPATIBLE: SEC: MCP over SSE answers only to localhost and the host names in the new setting `MCP_ALLOWED_HOSTS`, which remote clients and reverse proxies need
- INCOMPATIBLE: SEC: MCP: a read-only user can't change anything, a user limited to accounts or templates reaches only those hosts, and only an unrestricted global admin reads account passwords
- INCOMPATIBLE: SEC: The REST API and MCP no longer export or import accounts and users; use `rules export_all_rules` and `rules import_rules`
- INCOMPATIBLE: SEC: Archive needs the Hosts, Objects or hard delete permission; users limited to accounts or templates can't open, restore or delete archived hosts of others, and a link alone can't restore a host
- INCOMPATIBLE: SEC: Jinja templates: `datetime` no longer breaks out of the sandbox on Python 3.11 and older; `datetime.datetime.now()` keeps working
- INCOMPATIBLE: SEC: Container image: cron groups run again, they failed without a message since 4.4.0; they now run as the unprivileged user `app`
- INCOMPATIBLE: Cron Groups: a failed task, like a Checkmk export without connection, fails the group and stops the following tasks; set Continue on error where they should still run
- INCOMPATIBLE: Rules: Tag Match `equal` ignores upper and lower case again, as documented. Rules whose attribute name differs only in case did not match since 3.12.12 and match again, check them before you update
- INCOMPATIBLE: Rules: a Hostname Match regex with `\D`, `\S` or `\W` no longer does the opposite; it was turned into `\d`, `\s` or `\w`
- INCOMPATIBLE: Filter rules: a host set to Ignore is also left out when a rule works with a timestamp
- INCOMPATIBLE: Rewrite and Custom Attribute rules: `{{ FIRST_MATCHING_TAG }}` and `{{ FIRST_MATCHING_VALUE }}` hold what the first matching condition matched, also without rule debug; the misspelled `FIST_MATCHING_VALUE` keeps working
- INCOMPATIBLE: Ansible Playbook Fire Rules: conditions see the attributes of the project's Ansible inventory (inventory data, template labels, custom attributes, rewrites), not only the labels; check such rules, they can start playbooks now
- INCOMPATIBLE: CSV and NetBox imports: `delete_host_if_not_found_on_import` archives nothing after an import with errors or without hosts, and never a host with `no_autodelete`
- INCOMPATIBLE: i-doit export: an object with the same title counts as existing, whatever its type, CMDB status or monitoring, and is no longer created again in every run
- SEC: Users: only a global admin makes global admins and sees or lifts restrictions to accounts or templates; nobody changes a user with more rights, grants roles they don't hold or reads 2FA secrets
- SEC: Users limited to accounts or templates reach no other hosts in bulk actions, object details, debug, timeline, inventory, relations, Copy as new and the approval queue; Set Template offers only their templates
- SEC: A forced password change has to be done before any other page opens
- SEC: Account passwords no longer show on the Checkmk debug pages of hosts and Setup Rules, the user generation preview and the folder pages; View Cache Details needs Account Management, and the host debug page hides the i-doit token and the bakery passphrase and no longer renders attribute values as templates
- SEC: Accounts: proxy passwords are masked in the debug output and never logged
- SEC: Approval of critical labels: Bulk Edit Labels no longer gets around it, and nobody approves their own change
- SEC: Rules in Git: the repository address can't pass options to git, and symbolic links in the repository are refused
- SEC: Notifications: title and message templates can't run code on the server
- SEC: Autocreate Rules: an attribute value can't add fields to the created rule, quotes, backslashes and line breaks arrive unchanged; a host ignored by a filter rule no longer stops the run
- SEC: Saved searches and names in confirmation dialogs can't run code in the browser; shared saved searches are changed only by their owner or a global admin, and Cancel of bulk forms stays inside the Syncer
- SEC: MCP login: the response time no longer tells which of several users with the same login exists; such a collision goes to the audit log
- SEC: Updated joserfc, tablib, pylint, mcp and python-ldap; Ansible for Windows no longer installs `kerberos`, Kerberos login keeps working with `pykerberos`
- SEC: The docker compose files use MongoDB 8.0.34 instead of 8.0.4; the restart takes the data over

Fill in from checkmk.com sets version, edition and file per platform, appliance included; a button sets the newest patch release, the version is editable in the list, a Download Proxy can be set

# Version 4.4

## Unreleased
- FIX: A cronjob whose account is gone — for example after importing rules without the matching accounts — no longer breaks the Cronjob page; the group is listed with a note and can be opened to assign the right account
- FIX: Switching the JSON log stream on for imports, exports and cron no longer also requires the switch for the web application — each covers what it names
- FEAT: The JSON log stream can be written into a log file instead of stdout, so scheduled runs started from outside the container keep their records on disk — set JSON_LOGGING_FILE under Config → Local Config
- FEAT: The Checkmk rule export calculates its rules about three times faster, so a big inventory spends far less time in "Loop over Hosts and collect distinct rules"
